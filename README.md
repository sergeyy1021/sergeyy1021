## Serhii Klochko

*[Русская версия](README.ru.md)*

Electrical engineer (degree recognised in Norway by HKdir) with long hands-on
experience in industry and production — electrical, mechanical, maintenance, CAD
design and CNC. In recent years I have been building my own technical software
systems.

What I do best is connect two sides that rarely meet: the domain knowledge of how
something is actually calculated and manufactured, and the software that makes
that calculation verifiable. I write the specification, set the rules the work
has to follow, and accept the result by measurement and by running it — not by
reading the code. The code is largely written by AI agents under my direction;
the architecture, the domain knowledge, the decisions and the acceptance are mine.

**Domains.** Machine design — gearboxes, shafts, bearings, keys, and the
standards a calculation has to obey. Furniture manufacturing — cabinet
standards, joinery, hardware, and the whole chain from a panel to the machine:
DXF, MPR, NC / G-code for CNC. Applied ML — NLLB fine-tuning for ru→nb.

**Tools.** TypeScript, Node.js, React · Python · PostgreSQL, SQLite · Docker ·
Linux servers · SolidWorks, AutoCAD.

Several of my systems run on my own server and are ready to be demonstrated —
ask and I will open access. Open source here:
[Workbench](https://github.com/sergeyy1021/workbench), a protocol and tool for
AI-assisted development.

Looking for work in technical systems development, digitalisation of
production, production engineering, automation or technical project work —
where engineering and software meet.
